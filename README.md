# Friends Private Scripts

Private repository for useful Bash and Python scripts, shared only with our small group.

## 📋 Contents
- **Bash**: System automation scripts, backups, log parsing.
- **Python**: Tools for data processing, web scraping, daily utilities.

## 🚀 Quick Usage
- **View/Download**: Browse files directly on GitHub. Click "Raw" to copy code or download individually.
- **Run locally** (no Git needed):
  1. Copy script content from GitHub.
  2. Paste into a file (e.g., `backup.sh`), make executable: `chmod +x backup.sh`.
  3. Run: `./backup.sh` or `python3 myscript.py`.
- **Full setup** (optional, for editing):
  1. `git clone https://github.com/your-username/scripts-private.git`
  2. Install deps if needed: `pip install -r requirements.txt`
